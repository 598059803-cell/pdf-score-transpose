# 西贝柳斯原生交付

`.sib` 是西贝柳斯原生格式。开源部分交付 MusicXML/MXL，随后必须由本机 Sibelius 导入并保存 `.sib`。不要伪造文件头、改扩展名，或把 MusicXML 交付称为已完成 `.sib`。

## 打开与保存

1. 先完成 MusicXML 的声部、音程、节奏和代表性谱页检查，优先使用标准 MXL 容器导入。
2. 操作 Windows 软件时读取当前环境提供的 Computer Use 技能及其文档；窗口对象、截图和控件索引必须来自当前观察。这里不保存固定窗口 ID、坐标或第三方工具的过时 API 调用。
3. 在西贝柳斯中打开 MXL/MusicXML。其导入选项会影响乐器识别、页面与谱表大小、布局和乐器名称。按任务选择，确认 S/A/B、钢琴双谱表及打击乐对应正确。
4. 另存为用户目录中的新 `.sib`。若必须先保存到软件默认目录，先确认文件名不会覆盖既有文件，保存后再复制到交付目录，并比较文件哈希。
5. 仅关闭本次已保存的测试谱（不要关闭其他总谱），从交付路径重新打开实际的 `.sib` 文件，确认没有未保存标记，并核对声部、小节数与目标调号。记录“未测试 / 导入或保存受阻 / 已从交付路径重新打开”之一。仅运行 `scoretool verify-sib result.sib` 或重新看到尚未关闭的导入窗口，不算通过。

现有其他总谱如有未保存内容，先保留恢复稿，不能为本次转换丢弃用户的改动。

## 文件窗口或启动器故障

重新观察并选择当前窗口，按当前 Computer Use 工具的恢复规则重试。菜单可以响应但文件选择窗口不稳定时，可使用西贝柳斯支持的本机文件打开入口。Windows 原生命令行文件打开示意（用实际安装路径替换）：

```powershell
& 'C:\Program Files\Avid\Sibelius\Sibelius.exe' 'outputs\target.mxl'
```

它只负责打开，随后仍需要在软件中确认 MusicXML 导入并执行原生保存。应用启动期间可能先出现音源或快速启动窗口，不能把启动器标题当成总谱已打开。

不使用额外的 SendKeys、Win32 注入或盲目坐标来绕过 Computer Use 的停止/不可用状态。若本机没有 Sibelius、许可不可用或控制能力确实不可用，先交付可用的 MXL/PDF，明确 `.sib` 仍待本机导入保存；用户明确要求原生工程时不能把这一步报为完成。
